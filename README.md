# Spring Boot API Verification Demo

A personal Spring Boot project demonstrating REST API development, 
input validation, error handling, edge-case analysis, and API verification.

## Purpose

This project demonstrates how backend APIs can be designed and verified 
against expected behavior, including successful requests, invalid inputs, 
missing resources, duplicate data, and failure scenarios.

## Technology Stack

- Java 21
- Spring Boot
- Spring Web
- Spring Validation
- Maven
- REST APIs
- JUnit
- Mockito

## API Examples

### Create User
POST `/api/users`

### Get User
GET `/api/users/{id}`

### Update User
PUT `/api/users/{id}`

### Delete User
DELETE `/api/users/{id}`

## Verification Scenarios

The project will cover:

- Valid requests
- Missing required fields
- Invalid input
- Duplicate records
- Non-existent resources
- Invalid IDs
- Error responses
- HTTP status code validation
- Exception handling
- Edge-case behavior
